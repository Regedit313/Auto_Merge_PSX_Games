Simply start the .bat file to create the "ORIGINAL" folder.

Put all your PSX games in the "ORIGINAL" folder.
(mono and multi .bin)

Start the .bat file again and let the program work.

When it's finish, you gonna be invited to press any key and the program gonna quit.

Your merged PSX games are in the "MERGED" folder.

When you have copied your games on your game device, you can delete the "ORIGINAL" and "MERGED" folders and restart the .bat file to create the empty "ORIGINAL" folder.
